# 📦 حزمة الترويج المتبادل للعبة "تحدي المليونير أونلاين" داخل "أرض التحدي"

هذه الحزمة مجهزة بالكامل للنسخ المباشر داخل مشروع لعبة **أرض التحدي - أونلاين** (`com.qi7bali.landchallengeonline`) لترويج لعبة **تحدي المليونير** (`net.androidgaming.millionaire2024`) باحترافية وسلاسة.

---

## 📁 محتويات الحزمة:

### 1. لمشاريع Flutter:
- `flutter/cross_promo_millionaire_dialog.dart`: نافذة العرض المنبثقة السينمائية باللون الذهبي البنفسجي الأنيق.
  - طريقة الاستدعاء:
  ```dart
  CrossPromoMillionaireDialog.show(context);
  ```
- `flutter/cross_promo_millionaire_badge.dart`: الشارة العائمة النبضية المتحركة للشاشة الرئيسية.
- `flutter/cross_promo_millionaire_service.dart`: فحص التثبيت والفتح الفوري.

### 2. لمشاريع Android Native (Java / Kotlin):
- `android_native/CrossPromoMillionaireDialog.java`: كلاس الجافا للنافذة المنبثقة.
- `android_native/layout/dialog_cross_promo_millionaire.xml`: تصميم الواجهة الرسومي.
- `android_native/drawable/`: التدرجات اللونية والخلفيات.
- طريقة الاستدعاء:
  ```java
  CrossPromoMillionaireDialog.show(MainActivity.this);
  ```

### 3. لمشاريع Unity:
- `unity/CrossPromoMillionaire.cs`: سكربت C# جاهز لربطه بأي زر داخل محرك Unity لفتح متجر Google Play أو اللعبة مباشرة.
